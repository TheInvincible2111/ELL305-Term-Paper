# Diagrams

The paper's figures are drawn in LaTeX (TikZ and pgfplots) and live with the paper in `initial-draft-2/figures/`; Draft 1's are in `Draft 1/figures/`.

These folders are for editable sources of any other programmatic diagrams:

- `tikz/` - stand-alone TikZ figures
- `mermaid/` - conceptual flows and relationships
- `graphviz/` - dependency and topology graphs
- `wavedrom/` - timing diagrams (the course requires WaveDrom for these)
