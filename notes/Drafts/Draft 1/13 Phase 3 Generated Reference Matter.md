# Phase 3 generated reference matter

Phase 3 adds the required autogenerated navigation and reference pages.

## Generated front matter

- Table of Contents
- List of Tables
- List of Figures
- Glossary

The glossary definitions are maintained in `../../../Draft 1/glossary.tex`. They cover the technical terms actually used in Draft 1, including chiplets, CCD, IOD, cache hierarchy, 3D V-Cache, hybrid bonding, Infinity Fabric, TSV, and AMAT.

## Generated back matter

- Subject index with page references

Index markers are kept beside the relevant text in the modular section and appendix files. This allows page references to update automatically when the report changes.

## Build integration

`../../../scripts/build.ps1` now generates bibliography, glossary, and index data before the final LaTeX passes. Glossary generation uses MiKTeX's native `makeindex` executable directly, avoiding the optional Perl-dependent wrapper. The future single-file packaging script can inline the glossary definitions and retain the index commands, but it must not be run until a submission package is explicitly requested.
