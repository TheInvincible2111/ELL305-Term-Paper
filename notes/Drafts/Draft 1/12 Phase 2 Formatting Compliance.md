# Phase 2 formatting compliance

Phase 2 standardises the active report and future project templates around the new submission-format rules.

## Enforced settings

- A4 paper is declared by the active entry point and both reusable entry-point templates.
- The document base font is 12 pt.
- Text is explicitly single-spaced through the shared style.
- The page geometry uses one-inch margins on the top, bottom, left, and right.
- The shared header and footer remain inside the margin areas and do not alter the one-inch text-body geometry.

## Physical front-matter order

1. Cover page.
2. Copyright and intellectual-property assignment.
3. Acknowledgements.
4. Abstract.
5. Autogenerated table of contents.

The LaTeX source remains modular: the page order is controlled by `../../../Draft 1/front-matter.tex`, while the copyright and acknowledgements remain separate modules under `../../../Draft 1/front-matter/`.

The same shared style is imported by the future milestone and final-paper entry-point templates, so the Phase 2 page-format settings carry forward without duplicating them in each draft.
