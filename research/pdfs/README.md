# Research PDFs

Every source the paper cites must have its PDF in this folder (the course textbook lives in `../../sources/`),
so the project never depends on Downloads, Zotero storage or the web. Use stable descriptive filenames and record
the citation key in the matching reading note in `notes/Papers/`. Zotero stays the reference manager; it also keeps
its own copy of each attachment, but this folder is the project's copy. This folder is git-ignored.
